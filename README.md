# Ariel Data Challenge Collaboration Repo

This repository is shared by the team to collaborate on the same data challenge while keeping each person's notebook separate.

## How to contribute notebooks

1. Put your notebook in `/notebooks`.
2. Use a unique filename so everyone's work is easy to find and copy, for example:
   - `notebooks/loren-baseline.ipynb`
   - `notebooks/dana-feature-engineering.ipynb`
3. Commit and push your notebook changes regularly.

## Folder structure

- `notebooks/` – individual notebooks from team members
